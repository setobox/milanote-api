# 隐私与数据边界

## 官方服务

官方 API 实时处理请求，不存储分享链接、令牌、画板快照或请求配置，不提供自动更新。所有数据响应均为 Cache-Control: no-store，客户端和本项目的上游请求也禁用缓存。

分享链接放在 POST JSON 中，不放入本项目 API URL。输入仍会经过网络基础设施；本项目不缓存数据不代表第三方基础设施没有日志。

日志仅允许请求 ID、阶段、状态和耗时，不记录请求体、完整链接、令牌、画板响应或上游原始异常。

## 调试台

响应和完整历史重放仅在当前会话内存中。浏览器可在用户主动保存时保留请求配置；保存的分享链接含权限参数。自动历史只保留脱敏摘要，不包含分享链接、画板名称或响应内容。

复制代码、下载 JSON 是用户主动导出到自己设备的行为。服务端不会保存导出内容。

## 响应过滤

字段投影之前移除敏感键。include/exclude 只是数据选择工具，不是访问权限机制。服务端只允许解析 app.milanote.com 的 HTTPS 分享链接，不是通用代理。

## 自部署

存储与定时采集属于用户自己的部署。存储默认关闭。开启后由部署者管理数据库、R2、Actions 产物和 Webhook 接收方的访问权限。官方 GitHub Pages 不启用这些能力。
